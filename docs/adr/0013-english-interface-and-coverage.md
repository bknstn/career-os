# ADR 0013: Use an English interface and explicit title evidence

- **Effective date:** 2026-10-18
- **Status:** Accepted
- **Recorded:** 2026-10-22, retrospectively from the implementation history

## Context

The local interface needed consistent labels and clearer coverage across observed job titles. More classified titles must not be presented as an accuracy measurement.

## Decision

Use English for interface labels, dates, numbers, and accessibility text. Expand deterministic title evidence while preserving known assignments and showing unclassified counts.

## Consequences

No language switcher is included. Classification coverage remains distinct from measured accuracy, and skill counts remain literal mentions.
