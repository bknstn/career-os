# ADR 0000: Project purpose and evidence boundaries

- **Effective date:** 2026-08-17
- **Status:** Historical; evolved by ADR 0005 and ADR 0010
- **Recorded:** 2026-10-22, retrospectively from the implementation history

## Context

Career exploration needs inspectable observations from configured sources. A locally operated prototype can test useful questions before introducing hosted infrastructure.

## Decision

Build Career OS as a local career-intelligence experiment. Keep source provenance, uncertainty, and the configured population visible. Begin with a Market Explorer vertical slice and deterministic processing.

## Consequences

The repository contains the application and reproducible examples. Its reports describe collected evidence and cannot establish a representative global market, hiring probability, or a career forecast.
