# ADR 0017: Use the MIT license for the project

- **Effective date:** 2026-10-22
- **Status:** Accepted
- **Recorded:** 2026-10-22

## Context

The project initially used Apache License 2.0. The maintainer prefers the simpler
MIT terms used in other repositories and does not need the explicit patent
provisions of Apache License 2.0 for this project.

## Decision

Use the MIT license for the project. Replace the root license text and update
the README, SPDX license identifier, and package license classifier.

## Consequences

Users may use, modify, and distribute the code, including commercially, under
the MIT terms. Copies or substantial portions must retain the copyright and
permission notice. Third-party dependencies retain their own licenses.
