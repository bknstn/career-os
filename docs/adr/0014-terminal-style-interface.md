# ADR 0014: Adopt the terminal-style Radar interface

- **Effective date:** 2026-10-19
- **Status:** Accepted
- **Recorded:** 2026-10-22, retrospectively from the implementation history

## Context

The exploration interface needed a coherent visual identity while preserving the evidence and quality information already exposed.

## Decision

Use a dark terminal/radar visual style, responsive layouts, and radar motion in the existing JavaScript/CSS interface. Keep the source, quality, and evidence semantics unchanged.

## Consequences

The presentation evolves independently of collection and report contracts. Motion respects the interface implementation and does not imply live collection.
